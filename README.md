## 特色 / Features

- 🧰 **多功能** — 內建 YouTube・Bilibili・TikTok 解析，一般直鏈也通吃
- 🚀 **高速** — 多連線分塊下載＋可掛外掛 ffmpeg 合成音視訊
- 🧩 **瀏覽器擴充** — 內建擴充資料夾，一鍵與本機服務配對
- 🖥️ **跨平台** — Windows exe（免安裝）與 Android APP
- 🈶 **繁體＋簡體中文介面**
