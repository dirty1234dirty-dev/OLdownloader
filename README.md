跨平台高速下載器：YouTube / Bilibili / TikTok 解析、多連線加速、瀏覽器擴充、繁中介面。

## 特色

- 🧰 **多功能** — 影片 / 音訊 / 一般檔案，內建 YouTube・Bilibili・TikTok 解析
- 🚀 **高速** — 多連線分塊下載，可搭配外掛 ffmpeg 合成
- 🧩 **瀏覽器擴充** — 內建擴充資料夾，與本機服務無縫接軌
- 🖥️ **跨平台** — Windows / Android
